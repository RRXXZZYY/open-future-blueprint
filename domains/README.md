# 文明领域地图

版本：0.2 · 用途：议题导航与跨领域连接 · 分类状态：讨论草案

本目录以文明需要持续形成和维护的能力划分领域。目录序号不表示优先级；分区允许随实际贡献调整。

## 更深一级：科学如何继续划分

[D01 基础科学](foundational-science/README.md)首先区分学科，再记录研究问题，而非直接排列整个学科的高低。

例如：数学 → 计算与优化相关问题 → 某个明确命题或方法瓶颈 → 当前证据、依赖与研究路线。物理 → 凝聚态或流体等方向 → 某个明确理论、实验或测量问题 → 后续可检验路径。

这些例子说明记录层级，不是在推荐应优先资助的研究题目。

## 一个想法放在哪里

每个议题记录：主要领域、次级分区、相关领域、讨论层次、成熟程度、证据状态。

主要归属取决于“主要在解决什么问题”，相关领域通过标签和链接表达，避免把同一内容复制多份。例如：

| 议题 | 主要归属 | 相关领域 |
| --- | --- | --- |
| 某种新材料的基本性质 | D01 基础科学 | D02 工程、D03 资源 |
| 同一材料的可规模制造工艺 | D02 技术与工程 | D04 生产、D03 资源 |
| 用该工艺组织生产与供应 | D04 生产经济 | D02 工程、D07 制度 |
| 夜市服务信息如何帮助日常出行 | D05 生活 / 日常服务 | D08 空间连接、D04 经济、D07 治理 |
| 儿童活动与作品回顾 | D05 生活 / 家庭与成长支持 | D06 教育、D07 信息权利 |
| 住宅内部布局怎样被理解 | D05 生活 / 居住 | D02 呈现技术、D08 空间 |

同一组资源不能因为出现在多个领域中而被重复计入。

## 分类与优先级是不同问题

分类回答“在哪里讨论”；优先级回答“在某种目标与约束下，为什么现在推进”。后者需要[统筹方法](../framework/coordination.md)和[跨领域依赖](../framework/dependencies.md)。

尚无具体材料的分区只保留开放问题，不用自动生成的大量空文档制造内容已经完备的印象。
