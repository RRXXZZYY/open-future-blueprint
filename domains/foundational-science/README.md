# D01 · 基础科学与认识世界

状态：研究议题框架；尚无具体学科优先级结论。

## 二级分区

- 数学与逻辑：基础结构、证明、概率与统计、优化、计算相关理论等。
- 物理与天文：基本规律、物质结构、凝聚态、流体、宇宙与观测问题等。
- 化学：结构、反应、催化、测量与跨学科问题等。
- 生命科学：生命机制、系统组织、演化与基础测量等。
- 地球系统：地质、海洋、大气、气候与相互作用等。
- 复杂系统与交叉科学：跨尺度建模、网络、集体行为与研究方法等。

分区用于收集问题，可交叉归属，不构成学科发展的完整清单。

## “先突破什么”应怎样讨论

把候选问题写具体：已知什么、未知什么、为什么困难、哪些研究会受它影响，以及有没有绕开这一难题的路径。对未解问题更适合说“优先探索哪种路线”，而非承诺某年必然突破。

研究价值至少包括知识价值、帮助其他研究的价值、可能的实际价值和保留新方向的价值。近期用途暂不明确的研究，也可以提出清楚的知识目标、阶段性产物和复查安排。

## 每个候选研究议题需要什么

| 字段 | 要说明的内容 |
| --- | --- |
| 问题边界 | 精确问题、适用条件、现有结果及尚未解决部分 |
| 来源与核验 | 原论文、证明或数据；同行意见、复现或形式化核验的具体范围 |
| 价值与影响 | 对理解世界和其他研究的意义；可能应用与不确定性分别写 |
| 依赖 | 人才、算力、实验条件、数据、理论工具与合作网络 |
| 候选路线 | 方法 A、方法 B、绕开瓶颈的替代路线，各自前提 |
| 资源与阶段 | 资源类型、可取得程度、可观察的阶段进展，不虚构突破日期 |
| 复查条件 | 什么发现会提高、降低或改变这一路线的优先级 |

## 全局统筹如何保护研究空间

短期收入不能作为基础科学的唯一比较尺度。总体资源讨论应明确长期探索的持续安排，避免有潜力但尚无应用路径的研究被全部挤出。

同时，研究获得的资源和阶段结果需要记录；“长期”也不意味着永不复查。可以保留探索组合，在明确的假设失效或条件变化后调整。

## AI 科研成果如何进入蓝图

“提出证明”“公布可检查材料”“独立核验”“形成可用工程方法”是不同事实。需要分别记录工具贡献、人类贡献、核验状态和资源消耗。

已核对的近期公开材料见[证据记录](../../docs/evidence.md)。单项成果不能直接证明所有学科都能以同样方式推进，也不能据此宣布整个领域的资源排序。
