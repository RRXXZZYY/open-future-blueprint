# D05 · 生活、健康与社会照护

状态：领域导航与灵感区。

## 分区

居住与家庭、日常消费和服务、身心健康、照护、社区生活、无障碍与休闲。儿童活动的具体生活体验归入本区，教育方法与人才培养同时连接 D06。

## 如何连接更大的蓝图

生活改善可能依赖基础设施、可靠技术、生产供给与制度安排；生活体验的反馈也可能揭示值得研究的问题。提交新想法时，可以先描述具体场景，再补充这些关系。

日常生活贡献不必证明自己能够改变整个文明。全局蓝图需要能够容纳细小但真实的问题。
