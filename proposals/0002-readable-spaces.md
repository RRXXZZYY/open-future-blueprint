# 提案 0002：可理解的房屋空间

文明领域归属：[D05 生活灵感](../domains/life-and-wellbeing/README.md)。本文为局部议题的讨论材料，其中的试验构想不是当前执行任务。

状态：`构想` · 版本：`0.1` · 来源：发起者构想，AI 辅助整理与补充 · 负责人：待认领

## 目标与假设

让查看复杂住宅的人容易理解楼层、房间、出入口与动线，减少在连续镜头里迷失方向的情况。假设空间说明能帮助用户做初步判断，需要与现有平面图和短视频比较。

## 最小原型

选择一套有权使用资料的空间。先用虚构空间设计交互，再在获得资料授权后进行实际核对。呈现平面图、房间对应照片和可选的三维视图；点击房间可以了解它在整体中的位置。

AI 可以参与整理和展示制作；测量值、实际照片、人工核验结果、生成示意与模拟装修分别标注。缺失尺寸保留未知，不补成貌似准确的数值。

## 制度与责任

| 问题 | 草案处理方式 |
| --- | --- |
| 谁能授权资料展示 | 明确资料权利人与发布授权范围，发布者负责核对 |
| 谁对准确性负责 | 指定核验人，记录资料日期、误差和未核实区域 |
| 谁能修改 | 内容提供者提出更新，发布者保留版本和复核记录 |
| 模拟效果怎样呈现 | 持续标明模拟，不与实际交付状况混在一起 |
| 如何退出 | 支持撤下页面；明确已分享副本无法保证全部收回 |

## 资源与可持续性

分别记录资料采集、建模、人工核对、托管和修改工时。按空间制作收费、持续维护收费是候选方式，尚无付费意愿证据。

## 验证与顺序

让参与者分别使用平面图、短视频、交互空间说明，回答相同的布局与动线问题。记录理解正确率、任务时间、误解和偏好，再判断三维展示的增量价值。

先验证一个空间的准确表达和理解效果；再讨论模板化制作；多个案例证明复用价值后，才考虑通用建模工作流。

停止条件：资料授权无法确定、关键结构不能核验，或展示效果容易造成持续误解。试验开始前由负责人设定可接受误差与成本上限。

## 反对意见与开放问题

清晰平面图是否已经足够？三维模型会不会增加加载与制作成本？模型更新与实际装修不同步时如何提醒？自动解说是否比用户自行选择房间更有帮助？
