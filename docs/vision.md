# 人类未来文明：愿景与共同问题

状态：方向草案。本文描述要共同研究的问题，不预先替所有人决定理想生活。

## 项目的尺度

讨论对象是人类文明的整体发展：知识怎样增长、能力怎样形成、资源怎样使用、生产怎样组织、制度怎样协调、人的生活与文化怎样发展，以及如何给未来保留可能性。

城市是文明的一种空间组织形式，日常生活是观察文明的重要入口。它们与基础科学、生产体系、文化和公共制度共同构成讨论范围。

## 先讨论目标，再讨论快慢

“发展更好”可能包含多个目标：

- 扩大认识世界、创造知识与解决问题的能力。
- 改善基本生活、健康、学习与自主选择的条件。
- 形成持续供给和维护现实服务的生产能力。
- 使收益、风险和决定权的分布能够被解释和讨论。
- 维护生态、系统韧性与代际选择空间。
- 支持文化、关系、创造与意义，而不只增加物质产出。

这些目标之间可能有取舍。参与者应说明自己重视什么、愿意承受什么、不同人群可能怎么看；不把意见分歧藏进一个总分。

## 全局视角意味着连接

科学成果需要研究工具、实验条件与人才；生产和基础设施支持这些条件；教育、健康与文化影响人的参与；制度协调合作与成本；生态和资源条件限制可行范围。这些联系是需要逐项研究的命题，不是已经量化的完整模型。

项目应同时容纳长期知识探索、成果转化、基本服务、社会适应和系统维护。某个阶段可以集中突破关键瓶颈，同时为其他必要能力保留持续运转和更新空间。

## 借用《文明》系列的全局视角

“科技、生产、资源、文化、治理之间需要统筹”的观察有助于提出问题。现实中的依赖和效果需要证据，研究突破时间也无法像游戏里的回合数一样事先确定。

因此，我们记录可比较的路线、它们依赖的前提、适用地区、受影响群体与调整条件；允许不同社区或参与者提出不同发展组合。

## 当前共同工作

先建立领域地图、证据记录和路线比较方法，再逐步补充专业问题。早期没有专家参与的栏目明确标为“待研究”，不生成貌似权威的学科突破顺序。

新的发现、资源变化或社会反馈，可以改变先后顺序。文档要保留变化原因，以及被放弃路线中仍值得保存的知识。
