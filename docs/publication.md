# 项目发布与参与

公开仓库：[RRXXZZYY/open-future-blueprint](https://github.com/RRXXZZYY/open-future-blueprint)。

本项目公开讨论人类文明未来的目标、领域、资源与路线，以文档为主体。公开发布不表示任何机构采纳了方案，也不表示存在现实预算或已经启动实施。

## 参与入口

- [Discussions](https://github.com/RRXXZZYY/open-future-blueprint/discussions)：交流想法、反对意见和候选路线。
- [Issues](https://github.com/RRXXZZYY/open-future-blueprint/issues/new/choose)：记录明确的问题、证据缺口或文档修改建议。
- [修订记录](https://github.com/RRXXZZYY/open-future-blueprint/commits/main/)：查看公开文档的修改历史。

普通文字即可参与。正文由维护者协助整理，也欢迎使用 GitHub 网页提出修改。

## 状态如何理解

“发布”表示文档可以被阅读和讨论。“有阶段性证据”应说明被支持的具体命题和范围；不代表整个方案被证明正确。未解决的问题与重大不同意见应保留在正文中。
