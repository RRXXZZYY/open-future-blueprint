# 有限资源下的跨领域统筹

状态：讨论方法草案。尚未建立真实资源模型或计算任何文明发展最优解。

## 1. 先说明讨论范围与目标

记录地区、人群、时间跨度、当前状态和希望改善的目标。分别呈现知识进步、生产能力、基本生活、分配、自由选择、文化、生态与韧性等维度。

无法同意目标权重时，保留多个版本，比较路线在不同目标下的表现。所谓“更优”，必须说明相对哪一组前提。

## 2. 资源分别记账

资金只是资源之一。还需要记录人才与技能、算力与电力、实验和制造设施、材料与土地、时间、运营维护能力，以及组织协调条件。

各资源不可随意互换。追加预算不一定立刻得到熟练人员；可用算力不等于可用电力。组织信任等难以量化的条件可以定性记录，不能强行折算成资金。

对每种资源写：当前可用量、已有承诺、维持现有服务的需要、新增需求、估计范围、来源与核对日期。投入和收益的时间也要区分，不可拿预期未来收益支付当前已经缺少的资源。

## 3. 找到真正影响后续发展的限制

对候选行动区分：

- 缺少就无法继续的前提。
- 能明显加速或降低成本的支持条件。
- 可以采用其他方法绕开的依赖。
- 会争用同一批人才、资源或社会注意力的事项。
- 可能造成损害或引出新维护负担的影响。

每条关系注明证据、适用范围和不确定性。避免因某领域“看起来基础”就把所有后续活动都设为等待它。

## 4. 比较候选行动，而不只比较学科名称

| 讨论维度 | 要问的问题 |
| --- | --- |
| 紧迫性 | 不做会发生什么，等待成本是否增加？ |
| 对其他领域的帮助 | 能解除哪些关键限制，帮助是否需要其他配套？ |
| 直接改善 | 谁会受益，何时受益，谁可能承担代价？ |
| 可行性 | 当前资源和组织条件是否支持，哪些部分还未知？ |
| 总资源与机会成本 | 初期与持续成本各多少，会挤占哪些其他事项？ |
| 知识与探索价值 | 能否拓宽认识、验证关键假设或保留未来选择？ |
| 风险与可调整性 | 失败后能否退出，可能留下什么长期影响？ |
| 证据可信度 | 结论来自哪里，对哪些假设最敏感？ |

可以定性比较，也可以在有依据时给区间。不要把没有依据的分数相加，制造精确排名。

## 5. 形成相互支撑的投入组合

总体讨论应说明对以下工作怎样持续安排：

基础研究与长期探索；已有成果的工程转化；现实生产与基本服务；教育、制度和社会适应；生态与系统维护；应对变化的预备资源。

均衡的含义是让关键能力能够协调发展。不同阶段可以有不同重点，不要求各类别投入相等，也不预设固定百分比。

若某阶段集中投入一个瓶颈，应记录持续时间、被延后的事项、最低维持安排和复查条件。长期探索可以保留稳定空间，而不必把每个研究题目都证明为近期盈利项目。

## 6. 形成先后顺序与配套关系

硬性前提先满足；能够独立发展的事项可以并行；互相帮助的事项组成配套路线。记录每一步完成后，哪些下一步才成为可选。

论文、可靠工程方法、规模化生产与普遍可获得的服务是不同进展。不能只因某项理论有突破，就把制造、能源、技能、价格和制度条件都视为已经解决。

## 7. 比较多条路线，保留分歧

同时比较维持现状、近期改善、前沿突破和韧性优先等路线。若一种路线在科学上更强、另一种在近期生活上更好，应把取舍展示出来，让相关参与者讨论。

对需求上升、资源收紧、突破延迟、关键成果出现等情景进行纸面推演。优先关注在多种条件下仍可行、保留调整空间的方案，同时保留高不确定但可能有重要知识价值的探索。

## 8. 定期与事件触发的修订

每份路线提出适合其节奏的复查时间，以及触发条件：新证据、资源超限、关键依赖变化、持续维护不足或受影响者反馈等。

记录：曾经为什么优先，现在什么变化了，哪些项目继续、缩小、扩大、等待或转向。判断质量取决于解释与证据，不取决于是否永远坚持初始计划。

目前讨论的是公共知识与建议。实际资源由对应参与者和有权机构安排，仓库投票不构成对外资源分配决定。
